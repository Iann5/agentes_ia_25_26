# CRUD con JSON Server y CURL

Este proyecto demuestra cómo usar **JSON Server** para crear una API REST falsa y realizar operaciones **CRUD** usando **curl** desde un script Bash.

---

## Checklist de ejercicios

- [x] Configurar `json-server` con datos iniciales en `data/db.json`.
- [x] Crear script `scripts/peticiones_http.sh` para realizar operaciones CRUD con `curl`.
- [x] Añadir script en `package.json` para ejecutar el script (`npm run peticiones`).
- [x] Verificar que las operaciones GET, POST, PUT y DELETE funcionen correctamente.
- [ ] Incluir capturas de pantalla mostrando la ejecución del servidor y del script.
